## 1. 먼저 확인할 취약 어휘

뜻을 반대로 읽기 쉬운 표현부터 확인한다.

- **alter / altered** — 바꾸다 / 변화된 · ≈ transform
- **transform** — 변화시키다 · ≈ alter
- **thick / thicker** — 두꺼운 / 더 두꺼운 · ↔ thin
- **lack / lacking** — 부족하다 / ~이 없는
- **lack substance** — 실질적인 내용이 없다
- **pupil** — 동공 / 학생 · 눈 지문에서는 동공
- **diminish** — 감소하다 · ↓
- **deteriorate** — 악화되다 · ↔ improve
- **disperse** — 흩어지다, 분산되다 · ↔ gather
- **prior to** — ~보다 이전에 · = before
- **opposite** — 반대의 · ↔
- **inhibit** — 억제하다, 방해하다
- **wane** — 약해지다, 쇠퇴하다 · ↓
- **emerge** — 나타나다, 출현하다 · ↑
- **devoid of** — ~이 전혀 없는 · 결핍 표현; lacking보다 강한 의미
- **overlook** — 간과하다 · 살펴보다 아님
- **restrictive** — 제한하는, 구속하는
- **consequently** — 결과적으로, 따라서 · 원인 → 결과
- **deliberately** — 의도적으로 · = intentionally
- **intentionally** — 의도적으로 · = deliberately
- **harmless** — 무해한 · ↔ harmful
- **lead to** — ~을 초래하다 · → result in
- **contrast** — 대조하다 · ↔
- **undergo** — 겪다, 거치다 · undergo change

**복습 목표:** 단어를 모를 때 반대 의미로 추정해 문장 전체의 방향을 뒤집지 않는다.

<a id="section-8"></a>
## 8. 문제풀이 표현과 연결어

Day 16~19의 풀이에서 표현의 뜻과 문장 속 역할을 함께 확인한다.

- **설명/소개** — explain, describe, introduce
- **예시** — illustrate, provide an example
- **강조** — emphasize, highlight
- **주장** — argue, suggest, indicate
- **증명** — prove, provide evidence
- **비판/반박** — criticize, challenge
- **비교/대조** — compare, contrast
- **해결책** — present a solution

### Paraphrase · 문맥 속 바꿔쓰기

`contains` ≈ **includes**  
`compounds` → **mixture**: 교재 예문에서의 대응. 화합물과 혼합물 자체가 같은 개념은 아니다.  
`responsible` → **blamed**: 해당 피해 문맥에서 책임이 있다고 여겨진다는 의미의 대응.  
`damaging organisms` ≈ **harming living things**

Day 16에서는 **표시된 문장의 핵심 정보와 관계가 유지되는지** 확인한다. 예시·부연은 줄일 수 있지만 중심 의미를 누락하거나 바꾸면 안 된다.

### 연결어는 방향으로 암기

**원인 → 결과**

`because` = ~때문에  
`therefore` = 그러므로  
`consequently` = 결과적으로  
`as a result` = 그 결과  
`thus` = 따라서  
`for this reason` = 이런 이유로

**대조·반대**

`but / however` 하지만·그러나, `in contrast` 대조적으로, `on the other hand` 반면에.

`on the contrary`는 그와 반대로: 앞 진술을 부정하거나 바로잡는 맥락에 주의한다.

`nonetheless / nevertheless`는 그럼에도 불구하고: 앞 조건에도 뒤 내용이 성립하는 양보 관계다.

**같은 방향 ≈**

`similarly` / `likewise`

**예시 ↓**

`for example` / `for instance`

**추가 +**

`in addition` / `furthermore` / `moreover` / `also` / `besides`

<a id="section-11"></a>
## 11. 삽입 문제와 최종 점검

### 문장 삽입의 확인 순서

1. **문장의 역할:** 주제·주장인지, 설명·예시·결과인지 구분한다. 주제를 먼저 제시하는 두괄식 가능성도 검토한다.
2. **지시어:** this, that, these, those, it, they가 받는 대상이나 사건을 찾는다.
3. **관사:** a/an은 새 정보, the는 특정된 정보인지 살핀다. 관사만으로 위치를 확정하지 않는다.
4. **연결어:** 대조·원인·결과·추가 중 어떤 관계가 필요한지 확인한다.
5. **앞뒤 연결:** 앞 문장 → 삽입문 → 뒤 문장을 함께 읽고 흐름을 검증한다.

두괄식은 단서이며 모든 문단에 적용되는 공식은 아니다. the 역시 앞에 같은 단어가 반드시 있어야 한다는 뜻은 아니다.

### 연결어 빠른 확인

- **because** — 원인
- **therefore / thus / consequently** — 결과
- **however / in contrast** — 대조
- **nonetheless / nevertheless** — 양보: 그럼에도 불구하고
- **similarly / likewise** — 유사
- **for example / for instance** — 예시
- **moreover / furthermore / in addition** — 추가

### 복습 완료 체크리스트

- [ ] prior to, opposite, disperse, thicker의 방향을 바로 말할 수 있다.
- [ ] 변화·감소·악화를 구분하고 alter를 무조건 악화로 해석하지 않는다.
- [ ] overlook, address, pupil을 문맥에 맞게 해석한다.
- [ ] 문장 간략화에서 핵심 정보의 누락·왜곡을 확인한다.
- [ ] 문장 삽입에서 주제문 가능성과 앞뒤 연결을 모두 확인한다.
- [ ] 핵심 40개의 뜻을 가리고 회상한다.
- [ ] 철자가 헷갈린 단어는 영어를 가린 뒤 직접 쓰고 원래 표기와 비교한다.

**정리 기준:** 사용자 제공 어휘와 뜻을 보존하면서 대화체·반복 안내를 줄였다. 문맥에 한정된 paraphrase와 강도가 다른 유의어는 구별해 표시했다.
