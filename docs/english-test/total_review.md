# 교내 어학시험 영어 독해 복습노트

Hackers Updated TOEFL Reading Basic · 시험범위 p.196–275 · Day 15–20 및 Actual Test

## 자료와 사용 방법

이 노트는 이전 대화 **「대학원 수업 정리」** 의 사용자 학습 기록과 첨부된 **「교재 시험범위 _ 어학시험.pdf」** 를 대조해 작성했다. 단원명·페이지·문제 형식은 PDF에서, 성적·혼동 사례·직접 모은 어휘는 사용자 발언에서 확인했다. 풀이 절차와 체크리스트는 이를 바탕으로 새로 구성한 복습 안내다.

교재 문제를 대신하는 정답집은 아니다. 개별 오답 번호, 제출한 철자, 확인되지 않은 정답은 복원하지 않았다. 특히 단어 목록에 있다는 이유만으로 그 단어 때문에 실제로 틀렸다고 판단하지 않는다. 각 절의 **실제 학습 기록** 과 **재복습 포인트** 를 구분해서 읽는다.

페이지는 PDF 뷰어의 순번이 아니라 **책에 인쇄된 페이지** 를 뜻한다. 첨부 PDF는 두 쪽씩 촬영된 39면이며 p.196–263, p.266–275를 담고 있다. p.264–265는 첨부본에서 확인되지 않는다. Actual Test는 p.266에서 시작한다. 정답·해설 별책 내용은 이 첨부본에 없으므로 재채점할 때 보유한 교재 해설을 함께 사용한다.

### 한 단원 복습 순서

1. 단원 설명을 읽고 이번 유형이 **무엇을 근거로 답을 고르는지** 한 문장으로 말한다.
2. 교재에서 예전 오답과 확신 없이 맞힌 문제를 해설을 가린 채 다시 푼다.
3. 정답 번호를 보기 전에 근거 문장, 핵심 표현, 보기 탈락 이유를 적는다.
4. 해설과 비교해 오류를 `어휘 / 의미 방향 / 문장 구조 / 핵심 누락 / 근거 / 철자 / 시간`으로 분류한다.
5. 단어는 영어→뜻으로 확인한 뒤, 뜻→영어로 직접 써 본다. 다음 복습에서는 틀린 항목부터 확인한다.

권장 우선순위는 Day 16의 핵심 보존 → Day 19의 삽입 단서 → Day 20의 어휘·종합 적용 → Actual Test의 철자다. Day 15·17·18은 해당 약점과 연결해 병행한다.

## Day 15 · 지시어 문제

**교재 위치:** p.196–207. 개념 p.196–197 → Example p.198–199 → Daily Check-up p.200–203 → Daily Test p.204–207. [S1]

### 핵심 유형과 풀이 포인트

지시어 문제는 `it`, `they`, `their`, `this`, `those` 등이 실제로 가리키는 대상을 찾는다. 주변에 보이는 명사를 고르는 것으로 끝내지 말고, 그 명사를 지시어 자리에 넣었을 때 **문법과 의미가 모두 유지되는지** 확인한다.

1. 지시어가 있는 문장을 읽고 동사와 서술 내용을 파악한다.
2. 같은 문장과 앞 문장에서 후보 명사·명사구를 찾는다. 지시어가 앞의 사건이나 설명 전체를 받는 경우도 살핀다.
3. 단수·복수, 사람·사물 등 문법상 맞지 않는 후보를 제외한다.
4. 후보를 지시어 대신 넣고 다시 읽는다. 해당 대상이 실제로 그 행동을 하거나 그 속성을 지닐 수 있어야 한다.
5. 문맥이 어색하면 더 앞의 문장까지 범위를 넓힌다. 가장 가까운 명사라는 이유만으로 확정하지 않는다.

단원 대표 유형은 지시어지만, 실제 학습에서는 어휘와 시간 순서 판단도 함께 문제를 일으켰다. 재풀이 때는 질문이 지시 대상인지, 단어 뜻인지, 내용 확인인지 먼저 구분한다.

### 실제 학습 기록과 혼동

- **6문제 중 2오답** 을 보고했다.
- `altered`를 변화 일반이 아니라 눈이 약해지는 방향으로 해석했다. 이후 사용자 스스로 해설의 `transform`과 연결해 의미를 수정했다.
- `thicker`를 모른 상태에서 `thin`과 비슷하게 추정해 의미를 거꾸로 읽었다.
- `lacks substance`, `pupils`, `diminishes`, `deteriorates`, `disperses`를 몰랐다고 했으며, 특히 `disperses`는 반대 방향으로 유추했다.
- `avant-garde movement`는 개념을 대략 짐작했지만 영어 표기와 아방가르드 운동을 연결하지 못했다.
- `prior to`는 원래 알던 표현인데도 풀이 중 뜻을 회수하지 못해 시간 순서를 거꾸로 판단했다.

**교정할 습관:** 문맥이 부정적이라고 변화 동사까지 자동으로 ‘악화’로 해석하지 않는다. 단어의 기본 의미를 먼저 고정한 뒤 문맥에서 변화의 방향을 확인한다.

### 주요 어휘와 뜻

아래는 실제 혼동 사례와 사용자가 Day 15로 분류해 보낸 어휘의 핵심 항목이다.

- `alter / altered`: 바꾸다 / 바뀐. 변화 자체를 뜻하며 항상 악화는 아니다.
- `transform`: 변화시키다, 변형시키다.
- `thick / thicker`: 두꺼운 / 더 두꺼운. `thin`은 얇은.
- `lack substance`: 실질적인 내용이 없다, 내용이 빈약하다.
- `pupil`: 동공; 학생. 눈 지문에서는 동공이라는 의미를 먼저 확인한다.
- `diminish`: 줄어들다, 감소하다. 감소 자체가 항상 나쁜 결과를 뜻하지는 않는다.
- `deteriorate`: 악화되다, 나빠지다.
- `disperse`: 흩어지다, 분산시키다.
- `prior to`: ~이전에. 뒤에 오는 사건보다 앞선 시점을 표시한다.
- `simultaneously`: 동시에. `perceive`: 인식하다, 감지하다.
- `enclosed`: 둘러싸인. `pigment`: 색소. `coloration`: 색깔, 착색.
- `uterus`: 자궁. `uterine`: 자궁의. `undergo`: 겪다, 거치다.
- `indigenous`: 토착의. `linguistic`: 언어의, 언어학적인.
- `wane`: 약해지다, 쇠퇴하다. `emerge`: 나타나다, 출현하다.
- `sea otter`: 해달. `sea urchin`: 성게. `destructive`: 파괴적인.
- `medieval`: 중세의. `maritime`: 해양의, 해상의.
- `meticulously`: 꼼꼼하게. `archaeologist / archeologist`: 고고학자.
- `unearth`: 발굴하다. `inscribe`: 새기다. `syllabic`: 음절의.
- `recurring`: 반복되는. `dialect`: 방언.
- `cryptographer`: 암호 전문가. `decipher`: 해독하다.
- `administrative`: 행정의. `civilization`: 문명.
- `avant-garde movement`: 전위예술 운동, 아방가르드 운동.

## Day 16 · 문장 간략화 문제

**교재 위치:** p.208–219. 개념 p.208–209 → Example p.210–211 → Daily Check-up p.212–215 → Daily Test p.216–219. [S1]

### 핵심 유형과 풀이 포인트

Sentence simplification은 표시된 문장의 **핵심 의미를 보존하면서 간결하게 바꾼 문장** 을 찾는 유형이다. 글 전체에서 참인 설명이라도 지정 문장을 적절하게 바꿔 쓰지 않았다면 답이 될 수 없다.

여기서 ‘핵심 보존’은 모든 단어를 그대로 남긴다는 뜻이 아니다. 예시나 부연은 줄일 수 있지만 주된 주장, 주요 행위, 인과·대조·조건 관계를 없애면 안 된다. 관계절 역시 언제나 삭제 가능한 부분은 아니다. 어떤 대상을 특정하는 데 필수적이면 남겨야 한다.

1. 표시된 문장의 주어와 중심 동사를 찾는다.
2. 반드시 남아야 할 내용을 두세 덩어리로 적는다. `대상 / 핵심 행위·상태 / 핵심 관계`를 기본 틀로 쓴다.
3. 예시·나열·부연 설명을 구분한다. 무엇을 지워도 중심 주장이 유지되는지 확인한다.
4. 선택지마다 핵심 덩어리의 보존 여부를 점검한다.
5. 원인과 결과, 주체와 대상, 긍정과 부정, 가능성과 확정이 바뀌면 제외한다.
6. 본문 다른 부분의 사실을 끌어와 누락된 내용을 보충하지 않는다.

### 실제 학습 기록과 혼동

**22문제 중 13정답**, 9오답. 사용자는 표시된 문장과 일치해야 하는데 본문 전체 내용으로 맞는 보기를 골라 틀렸다고 설명했다. 오답에는 완전히 다른 내용뿐 아니라 중요한 내용이 빠진 경우도 있다는 점을 직접 파악했다. 단어 부족과 세부 해석의 어려움도 계속 보고했다. [S2]

따라서 복습의 중심 질문은 ‘이 선택지가 익숙한 이야기인가?’가 아니라 **‘표시된 문장이 말하는 핵심이 모두 남아 있는가?’** 다.

교재 p.209의 산성비 예시는 포함 성분에 대한 설명과 생물에 미치는 피해라는 중심 정보를 유지하고 예시·부연을 줄이는 과정을 보여준다. 해당 페이지를 펼쳐 원문, 핵심 정보, 바꿔 쓴 문장을 순서대로 대조한다. 정답 문장 전체를 외우기보다 남은 정보와 생략된 정보의 차이를 설명한다.

사용자가 Day 16으로 보낸 목록에서 핵심 판단에 도움이 되는 항목을 추렸다.

## Day 17 · 수사적 의도 문제

**교재 위치:** p.220–231. 개념 p.220–221 → Example p.222–223 → Daily Check-up p.224–227 → Daily Test p.228–231. [S1]

### 핵심 유형과 풀이 포인트

수사적 의도는 글쓴이가 특정 표현·사례·문장을 **왜 사용했는지** 묻는다. 내용의 뜻을 이해한 다음 그 부분이 설명·예시·강조·비교·반박 중 어떤 역할을 하는지 판단해야 한다. 단락 간 관계나 특정 기능을 하는 문장을 찾는 형식도 포함된다.

1. 질문에서 지정한 표현이나 문단을 찾는다.
2. 앞 문장의 주장과 뒤 문장의 설명까지 함께 읽는다.
3. 해당 부분을 지우면 무엇이 사라지는지 생각한다. 구체적 사례가 사라지는가, 근거가 사라지는가, 대조가 사라지는가?
4. 역할을 짧게 이름 붙인 뒤 선택지의 동사와 연결한다.
5. 지문에 등장한 내용이라도 글쓴이의 사용 목적을 설명하지 못하면 제외한다.

자주 읽을 역할 표현:

- `explain / describe / introduce`: 설명하다 / 묘사하다 / 소개하다.
- `illustrate / provide an example`: 예를 들어 보여주다 / 예시를 제공하다.
- `emphasize / highlight`: 강조하다 / 부각하다.
- `argue / suggest / indicate`: 주장하다 / 시사하다 / 나타내다.
- `provide evidence / prove`: 근거를 제공하다 / 증명하다. 근거 제시가 언제나 완전한 증명을 뜻하지는 않는다.
- `criticize / challenge`: 비판하다 / 이의를 제기하다.
- `compare / contrast`: 비교하다 / 대조하다.
- `present a solution`: 해결책을 제시하다.

추론 문제는 직접 쓰이지 않은 결론을 지문 단서로 판단한다. **지문이 뒷받침하는 결론** 과 그럴듯한 상상을 구분하는 것이 핵심이다. `infer`, `suggest`, `imply` 등이 단서가 된다.

1. 질문의 대상·시기·상황을 표시한다.
2. 해당 부분에서 직접 확인되는 사실을 짧게 적는다.

## Day 19 · 삽입 문제

**교재 위치:** p.244–255. 개념 p.244–245 → Example p.246–247 → Daily Check-up p.248–251 → Daily Test p.252–255. [S1]

### 핵심 유형과 풀이 포인트

문장 삽입은 문장의 뜻뿐 아니라 **앞뒤 문장과의 연결** 을 검사하는 문제다. 앞 문장과 잘 이어져도 뒤 문장의 지시 대상이나 논리 관계를 끊으면 적절하지 않다.

1. 삽입문이 주제·주장인지, 설명·예시인지, 대조·결과인지 먼저 분류한다.
2. `this / these / such / it / they`의 지시 대상을 찾는다.
3. `a / an / the`가 새 대상의 소개인지 이미 특정된 대상의 재언급인지 살핀다.
4. 연결어가 요구하는 원인·결과·대조·추가 관계를 확인한다.
5. 후보 위치에 넣고 **앞 문장 → 삽입문 → 뒤 문장** 을 한 묶음으로 읽는다.
6. 남은 위치가 하나가 되도록 다른 후보가 왜 어색한지 설명한다.

### 실제 학습 기록과 혼동

**20문제 중 16정답**, 4오답. 사용자는 새 유형인 삽입 문제에서 많이 틀렸으며, 두괄식으로 전개되는 글을 미괄식으로 생각해 위치를 놓쳤다고 명확하게 설명했다. 지시어·관사·연결어도 이후 복습의 핵심 단서로 정리했다. [S2]

### 파트별 교재 복습 안내

**p.266–267 · Module 1 안내와 철자 완성**

사막화 관련 문단이다. 먼저 문단의 주제와 흐름을 이해한 뒤 각 빈칸이 요구하는 품사를 찾는다. 제시된 앞부분 철자와 빈칸 길이, 문장 문법, 의미를 함께 확인한다. 추정한 단어의 뜻이 맞더라도 필요한 어미·형태가 다르면 그대로 답으로 쓰지 않는다.

사무실 이전 공지와 행사 등록 안내 이메일이다. 글의 목적, 해야 할 행동, 일정, 수신자에게 주어진 조건을 구분한다. 날짜가 여러 개이면 공지 날짜·기한·행사 또는 업무 시작일을 각각 적는다. 본문에 직접 적힌 사실과 그 사실에서 추론한 내용을 구분한다.

**p.270–271 · Circadian Rhythms**

일주기 리듬을 다룬 학술 지문이다. 정의 → 교란 요인과 영향 → 대응 방법의 구조를 표시한다. 어휘의 강도, 억제와 촉진의 방향, 제외 항목 질문, 문단 간 관계를 복습한다. 지문 이해 연습으로 읽고 외부 배경지식으로 답을 추가하지 않는다.

**p.272–273 · Module 2 안내와 철자 완성**

뼈와 성장 과정에 관한 문단이다. 대명사의 지시 대상, 생애 단계와 시간 흐름, 주어·동사의 수 일치, 문맥상 필요한 품사를 살핀다. 내용을 파악한 뒤 답을 완성하고 마지막에 철자만 따로 한 번 더 검사한다.

**p.274–275 · The Effects of Globalization**

세계화 관련 학술 지문이다. 확산의 원인, 문화적 영향, 문화적 정체성과의 조화 방식을 구분한다. 일부 부정적 영향이 언급됐다고 세계화 전체를 부정한다고 해석하지 않는다. 예시의 사용 목적과 지문이 직접 제시하는 행동을 확인한다.

## 누적 핵심 어휘 · 의미 방향별 회상

Day별 목록은 지문을 다시 찾는 용도이고, 아래 묶음은 단원을 섞어도 바로 뜻을 회상하는 용도다. 동의어 표시는 문맥상 가까운 의미를 나타내며 모든 문장에서 서로 바꿀 수 있다는 뜻은 아니다.

### 1. 변화·성장·촉진

- `alter / transform`: 변화시키다. 변화의 좋고 나쁨은 별도 판단한다.
- `emerge`: 나타나다. `thrive / flourish`: 번성하다.
- `foster / stimulate`: 촉진하다. `strengthen`: 강화하다.
- `broaden`: 넓히다. `accelerate`: 가속하다.
- `cultivate`: 기르다, 함양하다.

### 2. 감소·악화·방해

- `diminish / decline / wane`: 감소하다 / 감소·쇠퇴하다 / 약해지다.
- `deteriorate`: 악화되다. `exacerbate`: 악화시키다.
- `impair`: 손상시키다, 저하시키다.
- `inhibit / suppress`: 억제하다. `hinder`: 방해하다.
- `disrupt`: 정상적인 흐름을 방해하다. `restrict`: 제한하다.
- `mitigate`: 완화하다. 악화와 반대 방향으로 읽는다.

`wane`과 `emerge`는 문맥에서 쇠퇴와 등장으로 대비될 수 있지만 정확한 사전적 반의어 쌍은 아니다. 반대로 읽지 않는 것이 목적이지 서로 다른 뜻을 하나로 합치는 것이 목적은 아니다.

### 3. 결핍·충분함과 형태

- `lack / lacking`: ~이 없다 / 부족한.
- `devoid of`: ~이 전혀 없는. `shortage`: 부족.
- `ample`: 충분한. `rich`: 풍부한. `fertile`: 비옥한.
- `thick / thin`: 두꺼운 / 얇은.
- `opaque`: 불투명한. `restrictive`: 제한적인. `loose`: 느슨한.

### 4. 근거·판단·표현

- `evidence`: 증거. `interpret`: 해석하다. `overlook`: 간과하다.
- `suggest / indicate`: 시사하다 / 나타내다.
- `demonstrate`: 보여주다, 입증하다. `argue`: 주장하다.
- `depict`: 묘사하다. `convey`: 전달하다. `highlight`: 강조하다.
- `skeptical`: 회의적인. `doubt`: 의심하다. `criticize`: 비판하다.
- `favor`: 지지하다, 선호하다. `prevail`: 우세하다.

### 5. 관계·시간·방향

- `prior to`: ~이전에. `simultaneously`: 동시에.
- `throughout`: ~내내. `gradually`: 점차적으로. `ultimately`: 결국.
- `opposite`: 반대의. `disperse`: 흩어지다.
- `lead to`: ~을 초래하다. `consequently`: 그 결과.
- `nonetheless`: 그럼에도 불구하고.
- `rely on`: ~에 의존하다. `reconcile A with B`: A와 B를 조화시키다.
- `substitute A for B`: B 대신 A를 사용하다.

### 6. 학술 지문에서 다시 만날 표현

- `crucial`: 결정적으로 중요한. `relevant`: 관련 있는.
- `sustainable`: 지속 가능한. `distinctive`: 독특한.
- `resilience`: 회복력. `cohesion`: 응집, 결속.
- `symbiotic`: 공생의. `decompose`: 분해하다.
- `prey / predation`: 먹잇감 / 포식. `camouflage`: 위장.
- `terrestrial / marine / celestial`: 육지·지구의 / 해양의 / 천체의.
- `phenomenon / phenomena`: 현상 / 현상들.
- `deliberately / intentionally`: 의도적으로.

### 스스로 확인하는 방법

영어를 보고 뜻을 즉시 말한 뒤, 영어를 가리고 다시 적는다. 뜻이 늦게 떠오르거나 방향을 바꿔 말한 단어에는 별표를 붙인다. 다음 회차에는 별표 단어를 먼저 문맥에서 확인한다. `thicker`, `disperse`, `prior to`, `opposite`는 특히 **형태와 방향을 동시에** 확인한다.

## 연결어와 삽입 문제 규칙

### 연결어를 논리 관계로 읽기

- **순서:** `after` 이후, `later` 나중에, `next / then` 그다음, `finally` 마지막으로·마침내. `at the same time`은 동시성이다.
- **유사:** `similarly / likewise` 비슷하게·마찬가지로. 앞 내용과 같은 방향의 사례인지 확인한다.
- **대조:** `however / in contrast / on the other hand` 그러나·대조적으로·반면에. 무엇과 무엇을 대조하는지 적는다.
- **앞 진술의 반대:** `on the contrary` 그와 반대로. 단순한 다른 측면 소개보다 앞 진술을 부정·교정하는 맥락에 주의한다.
- **양보:** `nonetheless / nevertheless` 그럼에도 불구하고. 앞 조건에도 뒤 내용이 성립한다.
- **예시:** `for example / for instance` 예를 들어. 앞뒤에서 일반 진술과 구체 사례의 관계를 찾는다.
- **추가:** `in addition / furthermore / moreover / also` 게다가·또한. 같은 논점에 정보가 더해지는지 확인한다.
- **원인:** `because` ~이기 때문에, `due to` ~때문에. 원인이 어느 부분인지 표시한다.
- **결과:** `therefore / thus / consequently / as a result` 따라서·그 결과. 앞의 원인 또는 근거가 뒤의 결과를 설명해야 한다.

이 표현들은 의미 분류를 돕는 묶음이다. 접속사와 접속부사, 전치사구는 문법상 연결 방식이 다르므로 문장에 넣을 때 무조건 교체하지 않는다.

### 삽입 위치를 확정하기 전 여섯 질문

1. 삽입문은 주제문인가, 설명인가, 예시인가, 결과인가?
2. 두괄식이라면 뒤 문장들이 이 문장을 구체화하는가?
3. 지시어가 받는 명사·사건을 정확히 찾을 수 있는가?
4. 관사가 나타내는 정보 상태가 자연스러운가?
5. 연결어의 논리 방향이 앞 문장과 맞는가?
6. 삽입한 뒤 다음 문장까지 읽어도 연결이 유지되는가?

**피해야 할 자동 판단:** 가까운 명사니까 지시 대상이다 / `the`가 있으니 반드시 같은 단어가 앞에 있다 / 넓은 내용이니 결론이다 / 영어는 항상 두괄식이다. 각각은 문맥 검증을 생략한 판단이다.

## Paraphrase 패턴 · 표현이 달라도 무엇이 같아야 하는가

### 교재에서 확인한 표현 대응

Day 16 p.209의 예시는 다음 표현을 바꾸면서 중심 의미를 유지한다. [S1]

- `contains → includes`: 포함한다는 관계를 보존한다.
- `damaging organisms → harming living things`: 생물에게 피해를 준다는 의미를 보존한다.
- `responsible → blamed`: 해당 산성비 문맥에서 피해의 책임·원인으로 여겨진다는 의미를 연결한다. 모든 문장에서 같은 뜻은 아니다.
- `compounds → mixture`: 해당 예문의 문장 수준에서 사용한 대응이다. 화합물과 혼합물이라는 과학 용어 자체가 동일하다는 뜻으로 외우지 않는다.

Day 15의 사용자 기록에는 `altered`를 `transform`과 연결해 이해를 바로잡은 사례가 있다. 여기서는 변화라는 핵심을 보존하는지 확인하되 실제 선택지 형태는 교재에서 다시 본다.

### 일반적인 구조 복습 패턴

다음은 풀이를 돕기 위한 **일반 학습 패턴** 이며 특정 교재 문항이나 정답을 재현한 것이 아니다.

- **능동 ↔ 수동:** `A causes B`와 `B is caused by A`. 원인 A와 결과 B가 바뀌지 않아야 한다.
- **인과 표현:** `A leads to B`와 `B results from A`. 결과 뒤에 나온 명사가 원인일 수 있으므로 어순만 보지 않는다.
- **원인 절 ↔ 명사구:** `because + 절`과 `because of + 명사구`. 구조가 달라도 원인 내용이 같아야 한다.
- **품사 변화:** `X increases`와 `an increase in X`. 문장의 나머지 성분과 연결했을 때 동일한 변화를 말하는지 검사한다.
- **대조:** `although`나 `despite`를 바꿔 쓸 때 양쪽 사실과 양보 관계가 남아야 한다.
- **예시 축약:** 개별 사례를 일반 범주로 줄일 수 있으나 그 사례가 유일한 핵심 주장이라면 삭제하면 안 된다.
- **지시어 풀어쓰기:** `this / they`를 실제 지시 대상 이름으로 바꿔 쓰되 범위를 넓히거나 좁히지 않는다.

### 의미 보존 검사

- [ ] 누가 무엇을 하는지가 같다.
- [ ] 원인·결과, 비교 대상과 방향, 시간 순서가 같다.
- [ ] 부정과 긍정이 같다.
- [ ] 가능성·빈도·수량의 강도가 같다.
- [ ] 중심 주장이 빠지지 않았다.
- [ ] 원문에 없는 주장이 새로 들어오지 않았다.

Day 16에서는 이 검사를 표시된 문장에 적용한다. Day 17에서는 문장 기능을, Day 18에서는 추론의 근거를 추가로 확인한다. 서로 다른 문제를 모두 단순 동의어 찾기로 처리하지 않는다.
