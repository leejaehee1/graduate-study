# 🟣 6. 문제풀이 자체에 필요한 표현

이건 단어 문제뿐 아니라 **Day 16~19 유형을 풀 때 직접 사용**해야 하는 표현이야.

| 기능 | 표현 |
|---|---|
| 설명/소개 | explain, describe, introduce |
| 예시 | illustrate, provide an example |
| 강조 | emphasize, highlight |
| 주장 | argue, suggest, indicate |
| 증명 | prove, provide evidence |
| 비판/반박 | criticize, challenge |
| 비교/대조 | compare, contrast |
| 해결책 | present a solution |

### Paraphrase

`contains` ≈ **includes**  
`compounds` ≈ **mixture**  
`responsible` ≈ **blamed**  
`damaging organisms` ≈ **harming living things**

Day 16에서 네가 깨달은 것처럼 **본문 전체에서 맞는 말인지가 아니라, 밑줄 문장의 핵심 정보가 빠짐없이 유지됐는지** 보는 게 중요해.

### 연결어는 방향으로 암기

**원인 → 결과**

`because` = ~때문에  
`therefore` = 그러므로  
`consequently` = 결과적으로  
`as a result` = 그 결과  
`thus` = 따라서  
`for this reason` = 이런 이유로

**반전 ↔**

`but` / `however` / `in contrast` / `on the other hand` / `on the contrary`

**같은 방향 ≈**

`similarly` / `likewise`

**예시 ↓**

`for example` / `for instance`

**추가 +**

`in addition` / `furthermore` / `moreover` / `also` / `besides`

## 마지막으로 연결어 10초 복습

**because** → 원인  
**therefore / thus / consequently** → 결과  
**however / nonetheless / in contrast** ↔ 반전  
**similarly / likewise** ≈ 같은 방향  
**for example / for instance** → 예시  
**moreover / furthermore / in addition** → 추가

그리고 삽입 문제는 네가 Day 19에서 깨달았던 것만 기억해.

**① 두괄식 가능성을 먼저 생각 → ② this/that/these/it이 가리키는 앞 내용 찾기 → ③ however/therefore 같은 연결어 방향 확인 → ④ a/an은 새 정보, the는 앞에서 나온 정보인지 확인.**
